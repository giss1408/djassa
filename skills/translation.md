# Skill: Translation & Localization

Purpose: translate and localize content between French and English while preserving meaning and cultural context.

When to use:
- Translating finished drafts, UI text, or outreach materials.

Guidelines:
- Prefer natural-sounding translations over literal word-for-word conversions.
- Note culturally-specific terms and suggest localized alternatives.

Prompt pattern:
- Task: "Translate the following French text to English, preserve tone, and provide a 2-sentence note on any cultural nuances."

Contributor notes:
- Include original text and translated text in the same file.
