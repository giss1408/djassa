# Skill: Technical & Reproducibility

Purpose: ensure data, code, and analysis are reproducible and well-documented.

When to use:
- Preparing data tables, scripts, or reproducible analysis notebooks.

Requirements:
- Provide minimal runnable examples and environment notes (`R`, `Python`, or `Jupyter` kernels).
- Include input data references and exact commands to reproduce outputs.

Prompt pattern:
- Task: "Create a minimal script that loads <dataset>, performs <analysis>, and outputs <result>. Include exact commands to run."

Contributor notes:
- Add `requirements.txt` or `environment.yml` when sharing runnable code.
